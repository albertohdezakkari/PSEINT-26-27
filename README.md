# PSeInt Learning Studio

Web estática preparada para GitHub Pages.

## Contenido
- 10 ejercicios progresivos de PSeInt.
- Editor de pseudocódigo con guardado local.
- Pistas y soluciones desplegables.
- Checklist por ejercicio.
- Progreso guardado en localStorage.
- Test final de 20 preguntas autocorregible.
- Diseño responsive.

## Publicación
GitHub Pages debe publicar la rama `main` desde la carpeta raíz `/`.
